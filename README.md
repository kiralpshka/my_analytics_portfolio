# Анализ рекламных каналов онлайн-школы

## о чем проект
Анализ эффективности трёх рекламных каналов (Instagram, Facebook, Yandex) для привлечения учеников в онлайн-школу.

## что использовала
- Python (pandas, matplotlib)
- Jupyter Notebook

## что сделано
1. Посчитал общее количество регистраций по каждому каналу
2. Рассчитал конверсию (регистрации / посещения * 100%)
3. Определил самый эффективный канал
4. Построил график для визуализации
5. Дал рекомендации по распределению бюджета

## результаты
1.**Instagram** — лучший канал (299 регистраций)
2. конверсия в Instagram — 3.9%
3. рекомендация: увеличить бюджет на Instagram
